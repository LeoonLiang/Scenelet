开始前，你可能想知道

没有 Unsplash Key，也能用吗？

可以，直接导入本地照片即可。在线来源需要自己的 Access Key，并遵守 Unsplash 的 API 用途规则。

支持锁屏和多屏独立壁纸吗？

当前设置桌面壁纸，暂不支持锁屏、每块显示器单独设置或视频壁纸。

有哪些系统版本？

提供 Windows x64 / ARM64，以及 macOS Intel / Apple Silicon。Windows 7/8、32 位系统与 Linux 暂不提供安装包。Mac 包目前未完成实机壁纸验证。

在线模式可以公开使用吗？

Unsplash API Guidelines 将壁纸应用列入限制用途。个人 Key 不等于用途授权；公开推广在线模式前需确认服务方许可。建议先体验不依赖 API 的本地照片模式。
