# Scenelet 0.4 产品范围

目标：打开即可完成「连接 Key → 选择来源 → 开始换壁纸」，不需要理解图库管理或在偏好设置里寻找核心功能。

## 页面

| 页面 | 功能 |
| --- | --- |
| 换壁纸（默认首页） | Key 连接/保存/显隐/修改；分类、作者、Collection、官方主题、我的收藏或本地来源；方向、最低宽度、间隔；开始 |
| 浏览来源（按需进入） | 分页浏览当前来源、预览、收藏，可直接随机使用整个来源 |
| 我的收藏 | 用户精选的单一照片集合，预览、收藏/取消、用集合换壁纸 |
| 本地照片 | 导入照片或文件夹，预览、收藏、用本地集合换壁纸 |
| 偏好设置 | Key 管理副入口、布局、下载分辨率、缓存、托盘和开机启动 |

移除独立作者与合集管理、播放列表和历史页面。旧数据保留；内部历史继续用于避免近期重复，旧列表仍可读取且不做破坏性迁移。

## 交互原则

- 所有在线来源从公开来源池按需随机取图，只下载选中的壁纸，不要求先浏览或收藏。
- 分类关键词与官方主题分开。作者与 Collection 接受链接，解释两者含义。
- 收藏承担个人精选集合的用途，不再需要额外创建播放列表。
- 照片方向与真实原图宽度共同筛选。浏览筛选即时生效，轮换草稿点击开始后生效。
- 开始先设置第一张，成功后再启动定时器；失败暂停并保留现有壁纸。
- Key 成功连接后保留在输入框，默认遮盖，可点击查看；本机加密存储，重启恢复。
- 错误标明步骤，不自动消失。展开显示请求路径、HTTP 状态、服务端原因、剩余配额或网络错误代码，支持复制，隐藏 Key。
- 首次未连接时也提供直接导入本地照片的入口。
- 当前来源、是否自动换图、下一张始终可见。

## 验证边界

真实 Unsplash Key 在线端到端流程与 macOS 构建仍待实际环境验证。暂不增加多屏独立壁纸、视频、云同步、社区与自动更新。
