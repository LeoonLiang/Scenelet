# 文档截图

更新于 **2026-10-10 / v0.10.2**。截图直接取自 `npm run dev:web` 的真实 React 界面，使用内置 Unsplash 示例照片，没有连接个人账户或填入 Key。浏览器预览不执行系统壁纸、后台轮换或自动更新；截图不是这些系统功能的实机验收记录。示例照片尺寸不代表在线 API 元数据。

| 文件 | 展示内容 | 页面操作 |
| --- | --- | --- |
| `home.jpg` | 浅色首页、屏幕模型、候选照片 | 分类 → 山野 → 保存并收起，选中「此刻，停在湖边」 |
| `home-dark.jpg` | 深色首页 | 偏好设置 → 深色，回首页收起来源设置 |
| `gallery.jpg` | 浏览筛选与照片网格 | 山野 → 浏览并收藏，保留「仅横屏」 |
| `preview.jpg` | 大图预览 | 浏览页 → 此刻，停在湖边 |
| `custom-interval.jpg` | 来源与 45 分钟间隔 | 更换来源 → 自动换图间隔 → 自定义 → 45；裁切来源面板 |
| `import.jpg` | 本地 / 链接导入入口 | 我的图库 → 导入照片；链接输入框留空 |
| `menu-bar.jpg` | 菜单栏 / 托盘紧凑选图面板 | 首页保存在线来源后打开 `/#tray`，使用原生面板的 560 × 570 视口，选中「森林小径」 |
| `settings.jpg` | 清晰度、署名、外观与语言 | 偏好设置，浅色模式 |

除菜单栏面板使用原生窗口的 560 × 570 尺寸外，浏览器视口为 1280 × 720；首页与图库使用整页截图，导入、设置和大图使用视口截图，间隔设置裁切自整页截图。输出 JPEG。页面截图需等照片加载完毕，避免光标遮挡文字，不修改截图中的按钮状态、连接状态或功能表现。

`site/images/` 内的同名 JPEG 是此目录的逐字节副本，GitHub Pages 由独立 `gh-pages` 分支发布，不能引用站点目录之外的图片。更新时同步复制 `home`、`home-dark`、`gallery`、`import`、`settings`、`menu-bar` 六张图片，并更新 `site/index.html` 的尺寸、alt、截图日期和版本说明。README 使用本目录的相对路径。

临时截屏与页面检查图放到被忽略的 `artifacts/`，不要提交。最终检查图片加载、相对链接、站点桌面与手机布局，以及 GitHub Releases 下载选择；发布流程见 [发布文档](../releases.md#github-pages-介绍页)。
