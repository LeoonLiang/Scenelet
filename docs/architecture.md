# 实际技术架构

## 0.5 发布与更新

`electron/updater.cjs` 对接 electron-updater，使用 LeoonLiang/Scenelet 的公开 GitHub Releases。Windows 检测 NSIS 卸载器区分安装版与便携版；安装版后台下载、显式确认重启，不在退出时自动安装。便携版和未签名的 Mac 包仅检查版本并引导下载。更新服务不接收前端任意 URL，更新链接校验仓库与 HTTPS；开发及 smoke 禁用服务。

架构频道为 latest-x64 / latest-arm64，Mac 频道文件加 -mac 后缀，避免不同架构覆盖元数据。`scripts/build-release.cjs` 是本地与 Actions 的统一打包入口。四个矩阵任务构建后统一生成草稿 Release、上传 SHA256SUMS，再等待维护者发布。介绍页源码在 site/，通过 subtree 推送为独立 gh-pages 分支。

完整发布约定见 [版本发布](releases.md)。

0.4 对外名称为「拾景 · Scenelet」。保留 framewall 的应用数据目录、appId、IPC 和本地图片协议，升级不会迁移或丢失用户照片及凭据。

`electron/retry.cjs` 处理网络超时、临时连接错误与 HTTP 408 / 5xx，最多 4 次尝试，退避 1 / 2 / 4 秒；401 / 403 / 404 / 429 和证书错误直接报错。重试独立于候选照片的最多 3 批筛选。每次尝试创建独立超时信号，凭据变化取消后续重试。请求进度通过独立事件传递，使用请求标识避免并发请求相互清空提示。

轮换间隔允许 1–10080 整数分钟。前端提供自定义输入并在开始时校验，原生层规范化非法值为默认 60 分钟。定时器最大 7 天，不超过 Node 定时器限制。

## 运行边界

Electron main 处理官方 API、凭据、图片文件、系统壁纸、托盘和后台定时器。React 只通过白名单 preload 接口访问这些能力。启用 contextIsolation 与 sandbox，关闭 Node 集成，禁止页面新窗口与任意导航；IPC 校验发送窗口及主 frame。

`electron/core.cjs` 提供设置规范化、API 地址构造、图片尺寸过滤、有限分页扫描和轮换选图。`electron/main.cjs` 对接操作系统。`src/App.tsx` 为界面。

## 图片来源与筛选

支持发现流、关键词、作者 username、合集 ID、主题 slug，以及本地图片。图库在线来源每页 24 张，一次最多扫描 3 页；客户端保留 nextPage，不在加载更多时重新读取已扫描页。作者、合集、主题和搜索请求传递服务端方向参数，响应仍按真实 width/height 做过滤。

方向划分：宽高比 > 1.1 为横屏，< 0.9 为竖屏，其余为方形。最低宽度可设为 0 / 1920 / 2560 / 3840。筛选条件持久化并用于轮换池，不会因收藏混合尺寸照片而忽略筛选。

图库加载缩略图，大图预览按需加载，设置或下载时才获取用于壁纸的高清文件。作者/合集补取有扫描上限，没有匹配时由用户选择是否继续加载。

## 数据与凭据

应用数据目录内 `library.json` 保存已导入/收藏/使用照片、旧列表、历史和设置，通过队列与临时文件原子替换写入。`credential.bin` 为 Electron safeStorage 加密结果。0.3 增加受主窗口 IPC 校验保护的 credential 接口，向本机界面提供已保存 Key，供用户显隐及修改；Key 不进入 localStorage、普通配置或错误日志。无需 Secret Key。

本地图片协议只服务已经导入的文件，URL 使用文件路径哈希，不接受任意文件路径。在线 API 与图片下载校验 HTTPS 及精确主机名，拒绝重定向，下载限制 50 MB，读取后验证图片。

## 系统适配

Windows 使用 Unicode SystemParametersInfo 设置桌面壁纸，并配置系统填充模式；固定 PowerShell 脚本通过环境变量接收文件路径，避免路径插入代码。当前是系统桌面统一设置，非逐显示器设置。

macOS 通过固定 AppleScript 将图片设到系统桌面，以 argv 传递路径；需真实 Mac 上验证系统版本、自动化权限和多桌面行为。当前布局由系统决定。

原生定时器控制轮换，不依赖窗口可见。一次只执行一个壁纸任务，避免操作并发覆盖。顺序模式循环，随机模式避免紧邻重复。空池阻止启用，筛选变更造成空池会暂停。

在线轮换是独立来源：设置 rotationSource=online 和 onlineSource(kind/value/name)，保存时规范化用户名或 Unsplash 链接。启动无需本地收藏池，只要求有效在线来源与已连接 Key。定时器和手动下一张调用同一选图管线。

使用 `/photos/random` 限定 username、collections、topics 或 query，方向由接口与本地双重检查。主题 slug 解析为官方 ID 并缓存一小时。每个随机请求只获取 12 条候选元数据，一次换图最多尝试 3 次，不遍历全库。候选按原始宽高与最低宽度过滤，作者响应再核对 username；优先排除近期 20 张和当前图片。候选不足时可重用历史，但绝不切换来源来填补。

只有选中的一张进入高清下载、下载事件登记和系统壁纸管线。获取或下载失败时保留当前壁纸；获取途中更改来源、筛选或暂停自动轮换，会在设置壁纸前取消旧任务。断开 Key 会暂停在线轮换，离线不会自动改用其他作者的图片。

缓存清理保留当前壁纸。断网时已设置的壁纸保持，在线下载失败返回错误。开机启动仅允许已打包应用注册，不会在开发模式把 Electron 调试程序注册成启动项。

## 验证

18 项核心单元测试覆盖混合尺寸、最低分辨率、作者/合集分页地址、有限扫描及下一页游标、空池与轮换、请求主机校验、来源链接规范化、在线随机接口、作者核对、历史排除、有限随机重试、HTTP/网络错误详情、Key 脱敏、超时退避/恢复/取消及自定义间隔。

0.3 首页统一连接、来源、方向/宽度、间隔与开始入口。先暂停旧轮换并保存来源，成功设置第一张后再开启新定时器，失败保持暂停。筛选草稿在点击开始时统一生效，浏览筛选在页面内即时生效。后台更新中的错误与手动操作错误都进入持久错误面板。旧播放列表接口保留用于数据兼容，界面移除独立管理入口。

桌面 smoke 测试使用 `.smoke-data` 隔离数据，检查 preload、IPC、收藏、旧列表、本地真实尺寸与图片协议渲染；使用模拟网络和假 Key 验证加密文件、显式读取接口、移除与服务端错误详情。可选 Windows 壁纸测试保存系统原设置，在 finally 中恢复，并验证壁纸路径。

在线真实账户流程与 macOS 尚待实际环境验证。打包工具链还存在中等级上游依赖公告，详情见 README。当前 Windows 测试包未签名。
